写真フォルダ

ここに置いた写真は、assets/js/data.js の media（hero / prologue-portrait / prologue-wide / about）で指定します。
例）assets/img/hero.jpg（ファーストビューの静止画・動画のポスター）

・episodes/ … エピソードのポスター写真（縦長 4:5 推奨。例: ep-01.jpg）
・places/   … スポットの写真（横長 16:10 推奨。例: kaiyodai.jpg）

目安：長辺 2000px 前後、JPEG（画質80%前後）、1枚 500KB 以内。
ファイル名は半角英数字・ハイフンのみ（日本語・スペースは使わない）。
ogp.jpg（SNS共有用 1200×630）、favicon.svg、apple-touch-icon.png はサイトで使用中です。
